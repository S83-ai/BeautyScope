
# BeautyScope 💄

### Makeup Market Intelligence & Product Analytics

BeautyScope is a data-driven platform designed to analyse makeup products, pricing patterns, brand positioning and consumer insights in the Indian cosmetics market.

## Project Scope

- Market: India
- Brands: 8
- Target dataset: 750 makeup products
- Product categories: Face, Lips, Eyes, Nails and Makeup Tools

## Confirmed Brands

1. MARS Cosmetics
2. Swiss Beauty
3. Maybelline
4. Lakmé
5. Insight Cosmetics
6. NYX Professional Makeup
7. Colorbar
8. SUGAR Cosmetics

## Technology Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- SQLite
- HTML/CSS

## Project Objectives

1. Analyse makeup product pricing.
2. Compare cosmetic brands.
3. Explore product ratings and reviews.
4. Identify potential market opportunities.
5. Build an interactive analytics website.

## Data Collection

Primary retailer: Tira Beauty

Backup source: Official brand websites.

All collected records will retain their source information and collection dates.
